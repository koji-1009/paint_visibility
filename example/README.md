# paint_visibility_example

Demonstrates `package:paint_visibility`:

* **Fraction**: `PaintVisibility` reports the visible fraction of every list item on every frame.
* **Infinite**: `SliverRegionMarker` loads the next page when it enters the cache extent.
* **Marker**: `RegionMarker` detects that the end of a `Column` inside a `SingleChildScrollView` is visible.
